# P-mon 🖥️📡

> Lightweight, self-hosted monitoring for VPS, websites, Docker, and PM2.
> Built to run smoothly on a 1 vCPU VPS.

**P-mon** is a modern monitoring system inspired by nmon, rewritten from scratch in **Go + SQLite + Vue 3**. A single backend binary, a tiny agent on each VPS, and a real-time dashboard.

[🇧🇷 PT-BR](./README.md) · 🇺🇸 **English**

---

## ✨ Features

- 📊 **Servers** — CPU, RAM, Disk, Load, Network, Uptime via lightweight agent
- 🐳 **Docker** — monitor containers, alert when one goes down
- ⚙️ **PM2** — monitor Node.js processes
- 🔧 **Services** — nginx, mysql, redis, etc. via systemctl
- 🌐 **Websites** — HTTP status, response time, keyword search, SSL expiry
- ✅ **Checks** — ping, TCP, DNS, SSL expiry
- 🚨 **Alerts** — WhatsApp (PAPI), Email (SMTP), Webhook
- 👥 **Multi-user (SAAS)** — tenant isolation, roles (admin/member/viewer)
- ⚡ **Real-time** — dashboard updates via WebSocket, no reloading
- 🎨 **Whitelabel** — custom logo and colors per company
- 📈 **Uptime** — history with configurable retention

---

## 🏗️ Architecture

```
p-mon/
├── backend/     # Go — REST API + WebSocket + SQLite + scheduler + alerts
├── agent/       # Go — lightweight binary deployed on monitored VPS
└── frontend/    # Vue 3 — dark "mission control" dashboard
```

**Stack:**
- Backend: Go 1.21 + Gin + SQLite (modernc.org/sqlite, pure Go) + gorilla/websocket
- Agent: Go + gopsutil (single binary, ~5-10 MB, ~5-7 MB RAM in production)
- Frontend: Vue 3 + Vite + Pinia (SVG charts, no heavy dependencies)

## 🚀 Getting Started

### Backend
```bash
cd backend
cp config.example.json config.json   # edit the config
go mod download
go run ./cmd/server
# Server starts at http://localhost:8080
```

### Frontend
```bash
cd frontend
npm install
npm run dev      # dev at http://localhost:5173
npm run build    # production build in dist/
```

### Agent (on the monitored VPS)
```bash
# One-liner install (generated by the dashboard with collect flags):
curl -sSL "https://your-p-mon.com/install/agent.sh?key=YOUR_SERVER_KEY&docker=1&pm2=1&interval=180" | sudo bash
```

## 📦 Deploying on a 1 vCPU VPS

1. Build the backend: `go build -o p-mon-server ./cmd/server`
2. Build the frontend: `npm run build` → `frontend/dist/`
3. Configure `config.json` (JWT secret, SMTP, PAPI WhatsApp, base URL)
4. Run as a systemd service with Caddy in front (automatic HTTPS via Let's Encrypt)
5. SQLite is a single file — backup is just copying `p-mon.db`

**Actual production usage:** ~5-7 MB RAM (backend) + ~5-7 MB per agent host.

## 🔔 Configuring Alerts

In the dashboard → **Settings → Alert Channels**:

- **WhatsApp (PAPI):** paste your PAPI API URL + key
- **Email:** configure SMTP (host, port, user, password)
- **Webhook:** URL to integrate with Slack, Discord, etc.

Each monitor has configurable rules (threshold, occurrences, cooldown).
Server offline alerts fire automatically at `2× agent interval`.
